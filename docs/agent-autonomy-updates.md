# Agent Autonomy 강화 개요

## 에이전트 자율화 이전 상태 (`95d2615d45788649e8f484ee93df11fcfdb3124a`)
- 워크로그 뷰는 단순 이벤트 로그 수준이라 에이전트가 어떤 단계를 실행했는지, 실행 중 어떤 상태였는지 실시간으로 파악하기 어려웠습니다. 실시간 스트림이나 명령 이벤트 동기화가 없어 수동 확인에 의존했습니다.
- 플랜은 단순 텍스트로 처리되어 에이전트가 생성한 계획을 승인 없이 바로 실행했고, `StepManager`/`PlanContextManager` 같은 오케스트레이션도 존재하지 않아 단계별 진행이 체계적으로 추적되지 않았습니다.
- 툴 실행 승인 검토 워크플로가 없어 에이전트가 여러 툴을 임의로 호출했고, 실행 결과에 대한 통제권을 갖지 못했습니다.
- 에이전트가 활용할 수 있는 도구는 기본 파일 조작과 셸 실행 정도였고, 노트북 자동화·데이터 분석·프론트 명령 연계 같은 확장 툴체인이 준비되지 않아 VoC 같은 대용량 데이터 분석을 자동화할 수 없었습니다.

## Realtime Worklog Hub 구축
- `jai-worklog-card`와 `WorkNodeList`를 재구성해 에이전트가 자율 실행한 플랜·작업·최종 답변을 하나의 스트리밍 타임라인으로 통합했습니다. 따라서 에이전트가 어떤 결정을 내리고 어떤 단계를 자동 실행했는지 실시간으로 추적할 수 있습니다 (`82ee05c`, `bcf25eb`, `4f7952c`, `66c9411`, `18a7c77`, `f189a40`, `638391f`).
- 워크로그 노드를 명령 실행 이벤트와 직결해 에이전트가 수행한 명령, 중간 상태, 오류 대응까지 UI에 자동 기록되도록 파이프라인을 정비했습니다 (`95c81f6`, `97c3f18`, `a8292fa`, `ecbdb1d`, `f3515a4`, `a0b3381`, `0a0146c`, `464aec4`).

## Plan/Step Orchestration 레이어
- `StepManager`/`PlanContextManager`를 구축해 에이전트가 만든 계획을 직접 검토·승인하고 스텝별로 실행하는 런타임을 마련했습니다. 승인되지 않은 계획은 에이전트가 진행할 수 없으며, 승인 이후에는 자율 실행하면서도 모든 진행 상황이 기록됩니다 (`61d58ca`, `a9d3e6c`, `6f34cb1`, `1b7e3b7`, `7719c6d`).
- 도구 실행을 스텝 단위 리뷰·확정 절차로 제한해 에이전트가 자동 실행하더라도 안전장치가 작동하도록 했고, 실행 중 상태 전이부터 마감까지 에이전트 주도 거버넌스를 유지했습니다 (`09e8947`, `52236b9`, `901274a`, `c8e7078`, `5c9c200`, `10f0318`, `0aa910c`, `f552347`, `3c55317`).

## 플로우 라우팅 & 경량 답변
- `default_flow`는 이제 라우팅 프롬프트를 통해 에이전트가 직접 플로우를 선택합니다. 경량 질의는 레거시 `simple_flow`로, 복잡한 작업은 `planning_flow`로 위임돼 플랜 카드와 워크로그가 활성화됩니다. `plan_mode` 파라미터로 `always`/`never`/`auto`를 제어할 수 있습니다 (`f433f4c`).
- 플래닝 플로우 실행 시 reasoning 워크아이템을 자동 생성해 도구 호출 전 사고 과정을 워크로그 타임라인에 남기도록 했습니다 (`f433f4c`).

## AI Toolchain 확장
- 노트북 자동화 툴킷을 도입해 에이전트가 셀 생성·수정·실행, 노트북 열기, 커널 상태 대기 등을 자율 실행할 수 있게 했고, 모든 작업이 워크로그 요약과 상태로 남도록 구성했습니다 (`b4112a8`, `63584d8`, `3df71e6`, `7fa82f5`, `553f09d`, `25ed36f`).
- CSV 미리보기·프로파일링·필터링·집계·비교를 지원하는 `DataAnalysisToolkit`을 구축해 에이전트가 고객 피드백(VoC) 같은 대용량 데이터를 직접 분석하고 인사이트를 도출하도록 만들었습니다 (`5da4e67`, `4bbda53`, `df22008`, `df98552`, `13cdfc3`).
- 도구 실행 요약과 후크 체계를 강화해 에이전트가 문서를 자동으로 열고, 실행 결과를 요약하고, 워크로그에 필요한 메타데이터를 남기도록 했습니다. 새로운 도구군을 추가하더라도 에이전트가 자율적으로 활용하고 결과를 보고할 수 있는 기반을 마련했습니다 (`21f0311`, `ec8ff7e`, `ebf7971`, `ec3d1ee`, `3c0c0c3`).
